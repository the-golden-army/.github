# ⚔️ The Golden Army

### Engineering without compromise.

**The Golden Army** is an independent engineering organization focused on building software, developer tools, and systems with performance, reliability, and thoughtful design at their core.

We explore engineering challenges, experiment with new ideas, and turn them into practical, open-source software.

---

## What We Build

We work across different areas of software engineering, with a particular interest in systems programming and developer infrastructure.

- **Systems Engineering** — High-performance, reliable software built with Rust.
- **Developer Tools** — Tools that improve development workflows and productivity.
- **Infrastructure** — Exploring performance, efficiency, and scalable architectures.
- **Open Source** — Building in public and sharing useful engineering work.

## Our Principles

- **Performance matters.** We care about efficiency, not just functionality.
- **Engineering first.** Understand the problem before choosing the solution.
- **Simplicity wins.** Avoid unnecessary complexity.
- **Build in public.** Transparency and open collaboration make software better.
- **Continuous improvement.** Every project is an opportunity to learn and improve.
